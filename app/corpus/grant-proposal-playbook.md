# Grant Proposal Playbook (synthetic corpus document)

Proposals are assembled from a library of prior submissions, standard organizational boilerplate, and program-specific impact metrics. A first draft cites which library sections it reused so reviewers can check that reused language is still accurate.

Every funder-facing document requires named human sign-off. The drafting assistant produces a starting point, never a submission; the program lead owns the final text and the submission decision.

Impact metrics quoted in proposals must trace to the metrics repository. A metric without a repository entry is treated as unverified and is flagged, not silently included.
